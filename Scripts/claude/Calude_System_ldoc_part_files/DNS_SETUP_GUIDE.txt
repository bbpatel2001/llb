STEP 1: FIND YOUR DOMAIN REGISTRAR & DNS PROVIDER
═══════════════════════════════════════════════════════════════════════════════════

Common registrars:
- GoDaddy.com

2. Login to your account
3. Click "My Products" or "Domains"
4. Find coralrush.com
5. Click "Manage DNS"

STEP 4: DETAILED STEPS FOR GODADDY (Most Common)
═══════════════════════════════════════════════════════════════════════════════════

1. Go to https://godaddy.com and login

2. Click "My Products"

3. Find "coralrush.com" in Domains section

4. Click the three dots (...) next to domain name → "Manage DNS"

5. Scroll down to "Add" button

6. Add CNAME Record for API:
   ┌────────────────────────────────────┐
   │ Type:    CNAME                     │
   │ Name:    api                       │
   │ Value:   llb-api.onrender.com      │
   │ TTL:     3600                      │
   └────────────────────────────────────┘
   Click "Save"

7. Add CNAME Record for Quiz (get value from Vercel first):
   - Go to Vercel Dashboard
   - Select your project
   - Settings → Domains
   - Add Domain: quiz.coralrush.com
   - Vercel shows you a CNAME value
   - Copy and paste that value in GoDaddy
   
   ┌────────────────────────────────────┐
   │ Type:    CNAME                     │
   │ Name:    quiz                      │
   │ Value:   cname.vercel-dns.com      │ (or similar)
   │ TTL:     3600                      │
   └────────────────────────────────────┘
   Click "Save"

8. Wait 5-15 minutes for DNS to propagate

STEP 7: CONFIGURE RENDER (Backend Domain)
═══════════════════════════════════════════════════════════════════════════════════

After adding DNS record in registrar:

1. Go to Render Dashboard: https://dashboard.render.com

2. Select your service: "llb-api"

3. Go to Settings

4. Scroll to "Custom Domain"

5. Enter: api.coralrush.com

6. Click "Add Custom Domain"

7. Render confirms the DNS record

8. Wait 5-10 minutes for SSL certificate generation

Test:
```
https://api.coralrush.com/health
```

Should return: {"status": "healthy", "database": "connected"}

STEP 8: CONFIGURE VERCEL (Frontend Domain)
═══════════════════════════════════════════════════════════════════════════════════

1. Go to Vercel Dashboard: https://vercel.com/dashboard

2. Select your project: "llb-frontend"

3. Go to Settings → Domains

4. Enter: quiz.coralrush.com

STEP 10: TROUBLESHOOTING DNS
═══════════════════════════════════════════════════════════════════════════════════

Problem: "ERR_NAME_NOT_RESOLVED"
Solution:
  - Wait 15-30 minutes (DNS can take time)
  - Clear browser cache: Ctrl+Shift+Delete
  - Try different browser
  - Verify DNS records are correct in registrar
  - Check spelling: api (not api. or Api)

Problem: "SSL Certificate Error"
Solution:
  - Wait 10-15 minutes for certificate generation
  - Check Render/Vercel dashboards for errors
  - Verify domain is not used elsewhere
  - Verify DNS is pointing to correct service

Problem: "404 Not Found"
Solution:
  - Check that service (Render/Vercel) is running
  - Verify domain is added to service settings
  - Check if environment variables are set
  - Look at deployment logs for errors

Problem: "Connection Refused"
Solution:
  - Check if backend service is running
  - Verify MongoDB connection
  - Check Render logs for errors
  - Ensure API URL in React config is correct
