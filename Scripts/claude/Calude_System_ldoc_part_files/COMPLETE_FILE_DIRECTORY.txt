═══════════════════════════════════════════════════════════════════════════════════
WHAT EACH FILE DOES
═══════════════════════════════════════════════════════════════════════════════════

Backend API Files (Python):

1_app_main.py
  - Initializes FastAPI application
  - Loads all routes (questions, study, flashcards, progress, admin)
  - Sets up CORS for all domains
  - Defines startup/shutdown events (MongoDB connect/disconnect)

2_config.py
  - Loads all configuration from environment variables
  - Defines default values
  - Sets up database collection names
  - Configures API settings, file upload limits, etc.

3_database.py
  - Motor (async MongoDB) client
  - 40+ database operation methods
  - Auto-creates indexes on startup
  - Connection pooling and health checks

4_models.py
  - Pydantic models for request/response validation
  - Models for: Questions, StudyMaterials, Flashcards, Progress, etc.
  - Type checking and automatic documentation

5_routes_questions.py
  - 11 endpoints for question management
  - GET: questions, single question, by subject/year, search
  - Provides: subjects list, years list, types, duplicates, statistics

6_routes_study.py
  - 8 endpoints for study materials
  - GET: all materials, long answer, short answer, key points
  - GET: case laws, bare acts, MCQ, flashcard, revision notes

7_routes_flashcards.py
  - 6 endpoints for spaced repetition (SM-2 algorithm)
  - GET: due flashcards, statistics
  - POST: record review (updates easiness, interval, next review)
  - Delete flashcard

8_routes_progress.py
  - 7 endpoints for student progress tracking
  - Dashboard with overall statistics
  - Subject-wise progress
  - Weak areas detection
  - Study streak tracking

9_routes_admin.py
  - 8 endpoints for administrative tasks
  - Import questions from JSON
  - Import study materials from JSON
  - Export all data
  - Database statistics and maintenance

requirements.txt
  - Lists all Python dependencies
  - FastAPI, Uvicorn, Motor, Pydantic, python-dotenv, etc.
  - Install with: pip install -r requirements.txt

render.yaml
  - Render.com deployment configuration
  - Specifies Python version, build/start commands
  - Defines environment variables
  - Health check endpoint

Dockerfile
  - Creates Docker image for backend
  - Based on Python 3.11 slim
  - Installs dependencies and runs Uvicorn

docker-compose.yml
  - Orchestrates MongoDB + Backend locally
  - For development (optional)
  - Can also run frontend locally


Frontend Files (JavaScript/React):

api_client.js
  - Axios HTTP client for all API calls
  - Groups endpoints into: questionsAPI, studyAPI, flashcardsAPI, progressAPI
  - Error handling and request interceptors
  - 40+ API functions ready to use

vercel.json
  - Vercel.com deployment configuration
  - Specifies build command and output directory
  - Defines environment variables for production


WordPress:

wordpress-plugin.php
  - Adds REST endpoints to WordPress
  - Provides cached access to LLB API
  - Shortcode [llb_questions] to embed in pages
  - Admin settings page
  - Stores user progress in WordPress

SUPPORT & HELP
═══════════════════════════════════════════════════════════════════════════════════

If you get stuck:

API Issues:
  1. Check Render logs: dashboard.render.com
  2. Check MongoDB connection in .env
  3. Visit https://api.coralrush.com/docs to test endpoints

Frontend Issues:
  1. Check browser console: F12 → Console tab
  2. Check Vercel logs: vercel.com/dashboard
  3. Check if API URL is correct in .env

DNS Issues:
  1. Wait 15 minutes (DNS takes time to propagate)
  2. Use mxtoolbox.com to check DNS records
  3. Clear browser cache: Ctrl+Shift+Delete
  4. Verify CNAME records are correct in registrar

Database Issues:
  1. Check MongoDB Atlas: cloud.mongodb.com
  2. Verify IP whitelist includes 0.0.0.0/0
  3. Test connection string with mongosh CLI

WordPress Issues:
  1. Check plugin is activated
  2. Check WordPress error logs
  3. Test shortcode in a post/page
