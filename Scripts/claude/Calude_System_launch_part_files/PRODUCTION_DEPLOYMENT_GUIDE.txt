STEP 1: MONGODB ATLAS SETUP (Cloud Database)
═══════════════════════════════════════════════════════════════════════════════════

1. Go to https://www.mongodb.com/cloud/atlas

2. Create Free Account

3. Create New Project:
   - Project Name: "LLB Question Bank"
   - Create Project

4. Create Database Cluster:
   - Choose: M0 Sandbox (FREE)
   - Provider: AWS
   - Region: Choose closest to India (Mumbai: ap-south-1)
   - Cluster Name: "llb-cluster"
   - Create Cluster (takes 3-5 minutes)

5. Setup Security:
   - Database Access → Add New Database User
   - Username: llb_admin
   - Password: (Generate strong password - save it!)
   - Built-in Role: Atlas Admin
   - Add User

6. Setup Network Access:
   - Network Access → Add IP Address
   - Click "Allow Access from Anywhere"
   - Add 0.0.0.0/0 (for Render to connect)
   - Confirm

7. Get Connection String:
   - Clusters → Connect
   - Choose: "Connect your application"
   - Copy connection string:
   
   mongodb+srv://llb_admin:<password>@llb-cluster.xxxxx.mongodb.net/llb_question_bank?retryWrites=true&w=majority

8. Replace <password> with your actual password

9. Save this - you'll need it for:
   - Render environment variable
   - Local testing

STEP 5: CREATE & DEPLOY REACT FRONTEND
═══════════════════════════════════════════════════════════════════════════════════

A. Create React App:

```
npx create-react-app llb-frontend
cd llb-frontend
npm install axios react-router-dom chart.js react-chartjs-2
```

B. Create .env.production file:

```
REACT_APP_API_URL=https://api.coralrush.com
REACT_APP_ENV=production
```

C. Create .env.local file (for development):

```
REACT_APP_API_URL=http://localhost:8000
REACT_APP_ENV=development
```

D. Update src/api/client.js:

```javascript
import axios from 'axios';

const API_URL = process.env.REACT_APP_API_URL || 'http://localhost:8000';

export const apiClient = axios.create({
  baseURL: API_URL,
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json',
  },
});

// API functions
export const questionsAPI = {
  getAll: (skip = 0, limit = 20) =>
    apiClient.get('/api/questions', { params: { skip, limit } }),
  
  getById: (id) =>
    apiClient.get(`/api/questions/${id}`),
  
  search: (query) =>
    apiClient.post('/api/questions/search', { query }),
  
  getSubjects: () =>
    apiClient.get('/api/questions/subjects/list'),
  
  getYears: () =>
    apiClient.get('/api/questions/years/list'),
};

export const studyAPI = {
  getAll: (questionId) =>
    apiClient.get(`/api/study/${questionId}`),
  
  getLongAnswer: (questionId) =>
    apiClient.get(`/api/study/${questionId}/long-answer`),
  
  getShortAnswer: (questionId) =>
    apiClient.get(`/api/study/${questionId}/short-answer`),
  
  getKeyPoints: (questionId) =>
    apiClient.get(`/api/study/${questionId}/key-points`),
  
  getCaseLaws: (questionId) =>
    apiClient.get(`/api/study/${questionId}/case-laws`),
  
  getBareActs: (questionId) =>
    apiClient.get(`/api/study/${questionId}/bare-acts`),
  
  getMCQ: (questionId) =>
    apiClient.get(`/api/study/${questionId}/mcq`),
};

export const progressAPI = {
  getDashboard: (studentId) =>
    apiClient.get(`/api/progress/dashboard/${studentId}`),
  
  getBySubject: (studentId, subject) =>
    apiClient.get(`/api/progress/subject/${studentId}/${subject}`),
  
  updateProgress: (studentId, questionId, data) =>
    apiClient.put(`/api/progress/${studentId}/${questionId}`, data),
  
  getStreak: (studentId) =>
    apiClient.get(`/api/progress/streak/${studentId}`),
};

export const flashcardsAPI = {
  getDue: (studentId, limit = 10) =>
    apiClient.get(`/api/flashcards/due/${studentId}`, { params: { limit } }),
  
  recordReview: (flashcardId, data) =>
    apiClient.post(`/api/flashcards/${flashcardId}/review`, data),
  
  getStats: (studentId) =>
    apiClient.get(`/api/flashcards/stats/${studentId}`),
};
```

E. Create vercel.json:

```json
{
  "buildCommand": "npm run build",
  "framework": "react",
  "outputDirectory": "build"
}
```

OPTION C: WordPress REST API Bridge (Recommended)
────────────────────────────────────────────────

1. Create WordPress API endpoint that connects to your backend:

FILE: wp-content/plugins/llb-bridge/llb-bridge.php
```php
<?php
/*
Plugin Name: LLB Question Bank Bridge
*/

add_action('rest_api_init', function() {
  register_rest_route('llb/v1', '/questions', array(
    'methods' => 'GET',
    'callback' => 'llb_get_questions',
    'permission_callback' => '__return_true'
  ));
});

function llb_get_questions($request) {
  $api_url = 'https://api.coralrush.com/api/questions';
  $params = $request->get_query_params();
  
  $response = wp_remote_get(add_query_arg($params, $api_url));
  
  if (is_wp_error($response)) {
    return new WP_Error('api_error', 'Failed to fetch questions', 
      array('status' => 500));
  }
  
  return json_decode(wp_remote_retrieve_body($response));
}
?>
```

2. Use in React:
```javascript
// This prevents CORS issues
const response = await fetch('/wp-json/llb/v1/questions');
const data = await response.json();
```

STEP 8: CORS CONFIGURATION
═══════════════════════════════════════════════════════════════════════════════════

Update app/main.py for production CORS:

```python
from fastapi.middleware.cors import CORSMiddleware

allowed_origins = [
    "https://coralrush.com",
    "https://www.coralrush.com",
    "https://quiz.coralrush.com",
    "http://localhost:3000",
    "http://localhost:8000",
]

app.add_middleware(
    CORSMiddleware,
    allow_origins=allowed_origins,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

ERROR: MongoDB connection timeout
SOLUTION:
  - Check MongoDB Atlas IP whitelist (should be 0.0.0.0/0)
  - Verify MONGODB_URL environment variable
  - Test: mongosh "mongodb+srv://user:pass@cluster..."

ERROR: CORS errors in React console
SOLUTION:
  - Update app/main.py allowed_origins
  - Add your domain: https://quiz.coralrush.com
  - Redeploy backend

ERROR: 404 on quiz.coralrush.com
SOLUTION:
  - Check DNS CNAME records
  - Verify Vercel domain settings
  - Clear browser cache: Ctrl+Shift+Delete

ERROR: Backend returning 500 on production
SOLUTION:
  - Check Render logs: dashboard.render.com
  - Verify MongoDB connection
  - Check environment variables
