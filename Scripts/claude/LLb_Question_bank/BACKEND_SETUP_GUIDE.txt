STEP 1: CREATE PROJECT STRUCTURE
═══════════════════════════════════════════════════════════════════════════════════

Windows PowerShell (Run as Administrator):

```
cd C:\Users\<YourName>\llb_question_bank

# Create the app directory structure
mkdir app
mkdir app\routes
mkdir uploads

# Move main.py to app folder and rename
mv 1_app_main.py app\main.py

# Move config and database to app folder
mv 2_config.py app\config.py
mv 3_database.py app\database.py
mv 4_models.py app\models.py

# Move routes to app\routes folder

type nul > app\__init__.py

═══════════════════════════════════════════════════════════════════════════════════
STEP 2: INSTALL MONGODB (Choose one method)
═══════════════════════════════════════════════════════════════════════════════════

METHOD A: Using Docker (Recommended - Easiest)
──────────────────────────────────────────────

1. Install Docker Desktop from https://www.docker.com/products/docker-desktop/

2. Run MongoDB in Docker:
```
docker run -d `
  --name llb_mongodb `
  -e MONGO_INITDB_ROOT_USERNAME=root `
  -e MONGO_INITDB_ROOT_PASSWORD=password `
  -p 27017:27017 `
  mongo:7.0
```

3. Verify MongoDB is running:
```
docker logs llb_mongodb
```

You should see: "Waiting for connections"


METHOD B: Install MongoDB Locally
──────────────────────────────────

1. Download MongoDB Community Edition from https://www.mongodb.com/try/download/community

2. Run the installer and follow setup wizard

3. MongoDB will run as a Windows service (automatic startup)

4. Verify installation:
   - Open Command Prompt
   - Run: mongosh
   - You should see the MongoDB shell

5. Create root user (if needed):
```
use admin
db.createUser({
  user: "root",
  pwd: "password",
  roles: ["root"]
})
```


METHOD C: Use MongoDB Atlas (Cloud)
────────────────────────────────────

1. Go to https://www.mongodb.com/cloud/atlas

2. Create free account

3. Create cluster

4. Get connection string: mongodb+srv://username:password@cluster.mongodb.net/

5. Update in .env:
```
MONGODB_URL=mongodb+srv://root:password@cluster.mongodb.net/llb_question_bank
```

═══════════════════════════════════════════════════════════════════════════════════
STEP 3: SETUP PYTHON ENVIRONMENT
═══════════════════════════════════════════════════════════════════════════════════

1. Open PowerShell in your project folder:
```
cd C:\Users\<YourName>\llb_question_bank
```

2. Create virtual environment:
```
python -m venv venv
```

3. Activate virtual environment:
```
venv\Scripts\Activate.ps1
```

   If you get an error about execution policy, run:
```
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

4. Install dependencies:
```
pip install -r requirements.txt
```

   This will install:
   - FastAPI
   - Uvicorn
   - Motor (async MongoDB driver)
   - PyMongo
   - Pydantic
   - python-dotenv
   - And other required packages

═══════════════════════════════════════════════════════════════════════════════════
STEP 4: CONFIGURE ENVIRONMENT VARIABLES
═══════════════════════════════════════════════════════════════════════════════════

1. Copy .env.example to .env:
```
copy .env.example .env
```

2. Open .env and update:

For LOCAL MongoDB:
```
MONGODB_URL=mongodb://root:password@localhost:27017
DATABASE_NAME=llb_question_bank
```

For Docker MongoDB:
```
MONGODB_URL=mongodb://root:password@localhost:27017
DATABASE_NAME=llb_question_bank
```

For MongoDB Atlas (Cloud):
```
MONGODB_URL=mongodb+srv://root:password@cluster.mongodb.net/llb_question_bank
```

Save the file.

═══════════════════════════════════════════════════════════════════════════════════
STEP 5: RUN THE BACKEND SERVER
═══════════════════════════════════════════════════════════════════════════════════

1. Make sure virtual environment is activated:
```
venv\Scripts\Activate.ps1
```

2. Start the FastAPI server:
```
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

   Or simply:
```
python app/main.py
```

3. You should see:
```

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

ERROR: "ModuleNotFoundError: No module named 'fastapi'"
SOLUTION:
  - Make sure virtual environment is activated
  - Run: pip install -r requirements.txt
  - Restart PowerShell

ERROR: "Connection to MongoDB failed"
SOLUTION:
  - Verify MongoDB is running
  - Check .env MONGODB_URL
  - Test connection: mongosh mongodb://root:password@localhost:27017
  - If using Docker: docker ps (should show llb_mongodb running)

ERROR: "Port 8000 already in use"
SOLUTION:
  - Run on different port: uvicorn app.main:app --port 8001
  - Or kill process using port 8000

ERROR: "Permission denied" when activating venv
SOLUTION:
  - Run PowerShell as Administrator
  - Execute: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

═══════════════════════════════════════════════════════════════════════════════════
DOCKER COMPOSE METHOD (All-in-One)
═══════════════════════════════════════════════════════════════════════════════════

If you have Docker Desktop installed, you can run everything with one command:

```
docker-compose up -d
```

This will:
  ✓ Start MongoDB automatically
  ✓ Start FastAPI backend on http://localhost:8000
  ✓ Start Mongo Express UI on http://localhost:8081 (optional)

To stop:
```
docker-compose down
```
