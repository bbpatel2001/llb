2. LOCAL TESTING
   ─────────────
   Before deployment, test locally:
   
   python -m venv venv
   venv\Scripts\Activate.ps1 (Windows) or source venv/bin/activate (Mac/Linux)
   pip install -r requirements.txt
   copy .env.example .env
   (Edit .env with MongoDB local connection)
   uvicorn app.main:app --reload

3. GITHUB REPOSITORIES
   ────────────────────
   Create 2 repositories:
   
   • llb-question-bank (Backend - all app/ and config files)
   • llb-frontend (Frontend - entire frontend/ folder)
