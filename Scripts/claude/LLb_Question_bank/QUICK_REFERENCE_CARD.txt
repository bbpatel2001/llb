QUICK TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

Problem: "ERR_NAME_NOT_RESOLVED" (api.coralrush.com)
→ Solution: Wait 15 minutes for DNS, clear browser cache, check registrar

Problem: MongoDB connection timeout
→ Solution: Check IP whitelist is 0.0.0.0/0, verify connection string

Problem: CORS error in browser console
→ Solution: Update app/main.py allowed_origins, redeploy backend

Problem: 404 on quiz.coralrush.com
→ Solution: Verify Vercel deployment is live, check DNS records

Problem: API returns 500 error
→ Solution: Check Render logs, verify MongoDB connection, check env vars
