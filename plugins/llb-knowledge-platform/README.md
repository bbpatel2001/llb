# LLB Knowledge Platform WordPress Plugin

## Description
Complete LLB Knowledge Platform integration with WordPress.

## Features
- Custom post types for questions and flashcards
- Admin dashboard
- REST API support

## Installation
1. Upload to wp-content/plugins/
2. Activate from WordPress admin
3. Go to LLB Platform menu

## Requirements
- WordPress 5.0+
- PHP 7.4+

## Version
1.0.0
