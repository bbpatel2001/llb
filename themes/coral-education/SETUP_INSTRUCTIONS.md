# Coral-Education Theme Setup Instructions

## Overview
Coral-Education is a specialized WordPress theme for legal education institutions, law schools, and LLB programs with custom sections including question papers, case laws, and study materials.

## Initial Setup (After Theme Activation)

### Step 1: Go to Customizer
1. Login to WordPress Admin
2. Navigate to **Appearance → Customize**

### Step 2: Enable Sections
In the Customizer, you'll find **Home Page Settings** panel:

#### Enable Banner/Slider Section
- Go to **Home Page Settings → Slider Section**
- Check **Enable Slider Section**
- Upload banner image
- Add title, subtitle, and CTA button

#### Enable Info Section
- Go to **Home Page Settings → Information Section**
- Check **Enable Information Section**
- Add information content

#### Enable Welcome Section
- Go to **Home Page Settings → Welcome Section**
- Check **Enable Welcome Section**
- Select a page to display

#### Enable LLB Academy Section ⭐ (NEW)
- Go to **Home Page Settings → LLB Academy Section**
- Check **Enable LLB Academy Section**
- Fill in:
  - **Section Title** (e.g., "LLB Academy")
  - **Subtitle** (e.g., "Master Law Degree Program")
  - **Description**
  - **Section Image** (Upload image)
  - **Button Text** (e.g., "Explore Programs")
  - **Button Link** (e.g., /programs/)
  - **Features** (Separate by | symbol)
    Example: `Expert Faculty|Comprehensive Curriculum|Study Materials|Practice Tests`

#### Enable Featured Courses
- Go to **Home Page Settings → Featured Courses Section**
- Check **Enable Featured Courses Section**

#### Enable Other Sections
- Enable Testimonials, Blog, Gallery, Search sections as needed

### Step 3: Set Front Page
1. Go to **Settings → Reading**
2. Select **Static Page** for "Front page displays"
3. Create/Select a page as your front page
4. Save changes

### Step 4: Configure Site Details
1. Go to **Settings → General**
2. Update:
   - Site Title: Your institution name
   - Tagline: Your tagline
3. Go to **Settings → Site Identity**
4. Upload custom logo

## Key Features

### Custom LLB Sections
- **Question Papers Section**: Browse exam papers organized by subject/year
- **Case Laws Section**: Important court judgments
- **Acts & Statutes**: Legal reference material
- **Study Materials**: Notes, flashcards, MCQs

### Customization Options
All sections can be customized via **Appearance → Customize → Home Page Settings**

### Colors & Branding
- Primary Color: Law Blue (#1a3a52)
- Secondary Color: Legal Red (#c41e3a)
- Accent Color: Gold (#f39c12)

## Troubleshooting

### Sections Not Showing
- **Solution**: Make sure they are enabled in Customizer
- Check if you're using a static front page (not blog posts)

### Banner Not Visible
- Go to **Customize → Home Page Settings → Slider Section**
- Check **Enable Slider Section**
- Make sure you've uploaded a banner image

### LLB Features Not Showing
- Go to **Customize → Home Page Settings → LLB Academy Section**
- Fill in all fields (Title, Subtitle, Description, etc.)
- Features must be separated by | symbol

### Images Not Loading
- Check file permissions on the server
- Ensure WordPress Media Library is accessible
- Try re-uploading images

## Content Management

### Adding Pages
1. Go to **Pages → Add New**
2. Create pages for:
   - About Us
   - Programs
   - Contact Us
   - Faculty
   - etc.

### Adding Blog Posts
1. Go to **Posts → Add New**
2. Create posts for news, updates, announcements

### Organizing Content
Use **Categories** and **Tags** to organize blog posts

## Support
For issues or questions:
1. Check WordPress Admin for error messages
2. Verify all customizer settings are saved
3. Clear browser cache and WordPress cache
