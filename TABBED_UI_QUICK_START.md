## 🖱️ How to Use

### Viewing a Question

1. **Navigate** to Questions page
2. **Click** on any question
3. **Land on** Question tab by default
4. **Read** the full question
5. **Check** metadata (marks, type, etc.)

### Viewing Answers

1. **Click** "Answers" tab
2. **See** answer preparation buttons
3. **Click** "Prepare Short Answer" or "Prepare Long Answer"
4. **Wait** for answer to be prepared (3-5 seconds)
5. **Read** comprehensive answer with key points and tips

### Comparing Questions & Answers

1. **Click** Question tab → read question
2. **Click** Answers tab → review answer
3. **Click** back to Question tab anytime
4. **Switch** quickly between tabs as needed
