## Interaction States

### Buttons
```
Default:   Blue background, white text
Hover:     Darker blue background
Active:    Blue background with shadow
Disabled:  Gray background, reduced opacity
```

### Tabs
```
Active:    Blue text, blue underline, light blue bg
Inactive:  Gray text, no underline, no bg
Hover:     Gray text becomes darker, light gray bg
Focus:     Blue outline (keyboard navigation)
```

### Cards
```
Default:   White background, subtle shadow
Hover:     Deeper shadow effect
Focus:     Blue outline (keyboard)
```
